# Bulkbooks

A book category management system built with ASP.NET Core MVC, using Entity Framework Core and SQL Server for data persistence.

## Tech Stack
- ASP.NET Core MVC
- C#
- Entity Framework Core
- SQL Server
- HTML/CSS

## Features
- Create, edit, and delete book categories
- List all categories with display order
- Server-side validation (e.g., prevents a category's display order from matching its name)
- Success notifications on create/update/delete actions
